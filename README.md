# HYPR Star Dotfiles

## 🚀 Descripción
Una colección de archivos de configuración (dotfiles) para crear un entorno de escritorio Linux personalizado y elegante utilizando Hyprland.

## ✨ Características
- Configuración completa de Hyprland
- Tema visual personalizado
- Configuraciones optimizadas para productividad
- Scripts de utilidad incluidos

## 📦 Requisitos
- Hyprland
- Waybar
- Kitty
- Rofi
- swww (para fondos de pantalla)

## 🛠️ Instalación
1. Clona este repositorio:
```bash
git clone https://github.com/biglexj/HYPR-Star-dotfiles.git
```
2. Ejecuta el script de instalación:
```bash
cd HYPR-Star-dotfiles
./install.sh
```

## 🔧 Configuración
Los archivos de configuración se encuentran organizados en las siguientes carpetas:
- `hypr/` - Configuraciones de Hyprland
- `waybar/` - Configuración de la barra de estado
- `rofi/` - Temas y configuraciones del lanzador
- `scripts/` - Scripts de utilidad
